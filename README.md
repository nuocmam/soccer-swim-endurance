# The Engine and the Pitch

Long-form essay: swimming and deep-water running as soccer endurance *conditioners*, not as substitutes for pitch running. First-principles physiology, sourced numbers only.

Open `index.html`. Every kilometre, bpm, and week-count is from a fetched paper or FIFA/UEFA page. Unverified claims are labelled. Not a session plan for a player in the 8–10 range. Privacy-scrubbed: no family names.
